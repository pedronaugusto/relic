# Architecture phase 2 — work in progress

Phase 2 is not landed. Baseline: published main
[`67077cb`](https://github.com/pedronaugusto/relic/commit/67077cb2293a8ce3489da007186bc2964e4ef3d9).
The architecture mission in the owner's book remains authoritative. No phase 3/4

## Implemented, awaiting the complete phase gate

- F02: independently owned pack keep tokens survive receipt, fetch/clone ref
  publication and deferred cleanup; overlapping tokens preserve each other.
  Contracts cover Git repack/prune before refs, ref-commit failure, cancellation,
  allocation failure, files/reftable and SHA-1/SHA-256 where applicable.
- F08: HTTP and SSH lock list/verify terminate on missing or empty cursors,
  reject repeated/cyclic cursors, and save caches only after complete success.
- F10: one BRE/ERE/GNU parser and execution core serves boolean and span queries.
  Newline policy belongs to adapters. Complexity is bounded, allocation-failure
  cleanup uses shakedown NoResize, and small VM scratch requires no allocation.
- Extraction findings: long includeIf patterns, quoted attribute escapes, shared
  pathspec grammar for stash/rerere/submodule.active, one LineDiff parser, the
  1023 MiB diff limit, and one Sweep Set per ignore/attributes/sparse level.
- Moves I–III, pure root facades, canonical concern names, repository accessors,
  and the initial lifecycle/options/error cleanup are implemented in this branch.
- Airlock owns durability calls; the copied filesystem durability implementation
  is removed. Warp owns CRC checksums; the local CRC implementation is removed.
- Conduit owns Term. Relic wraps Child and uses shakedown's allocator checks.

## Published dependency requirements

These are requirements, not waived gates. Pins come only from green published
main; snapshots with exact SHAs and run records are retained beside this report.

- Warp main `e607c194`: whole-buffer codecs are published, but Relic needs
  streaming inflate/compress readers/writers and reset semantics. W5 is not
  published main and is not pinned. Relic's streaming codec implementation remains
  until the dependency can replace it without a local copy or compatibility shim.
- Parallax main `b1acc95d`: whole-patch parse/apply does not expose a raw hunk seam
  that preserves Git extended headers, recount policy, and Git hunk-body rules.
  Relic hunk parsing is still present; adoption remains required.
- Preflight main `b28046cc`: its Gantry dependency lacks Layer.exports, facade
  purity and collapsed-directory cycle enforcement. Direct-member imports and normal module/type alias chains also
  produce false unused-import reports. The alternate import-style experiment
  is retained in lint-current.txt and was reverted because it did not fix
  the classifier. Relic has no local planner or graph waiver.

There is no nav communication capability exposed to this worker. Dependency
requirements have been raised in task progress and are recorded here for nav.

The regressions are unresolved and block landing. Later compiler optimizations
need a fresh quiet pair. `reserved-hot` records a rejected allocation experiment;
that experiment was reverted. `sets-*` samples used a Debug executable and are
invalid for A/B conclusions. Other concurrent-build samples are exploratory only.
No timing gate is waived and CI does not gate on noisy timings.

Targeted test logs retain before/after regression evidence and the publication
fault/cancellation proofs. Full-suite validation belongs to CI. No merge-tier run
has been dispatched and no landing SHA exists yet.
